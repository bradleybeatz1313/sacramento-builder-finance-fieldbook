# Sacramento Builder Finance Fieldbook

A source-backed builder prospecting and application-generation fieldbook for a New American Funding loan officer serving greater Sacramento.

## Scope

Sacramento County plus Placer, El Dorado, Yolo, and nearby commuter markets. Builder and community details were reviewed in August 2026 and should be reverified before outreach.

## Commands

```bash
npm install
npm run check
npm run test:browser
npm run dev
```

## Important

This is business-development guidance, not legal advice. Any builder agreement, co-marketing, sponsorship, desk arrangement, lead sharing, incentive, advertising, or item of value requires New American Funding compliance/legal approval.
